# Koutaro Demo — نسخة متعددة الصفحات

متجر تجريبي بصفحات: الرئيسية، السلة، تأكيد الطلب، نجاح الطلب، حقوق الموقع. الطلبات تحفظ محليًا في orders.db.

## تشغيل على Windows داخل VS Code

افتح المجلد الذي يحتوي على app.py في VS Code ثم افتح Terminal ونفذ:

```powershell
python -m pip install -r requirements.txt
python app.py
```

افتح http://127.0.0.1:5000

لإيقاف الخادم Ctrl+C. لا تضع بيانات حقيقية؛ المشروع تجريبي وغير مهيأ للنشر العام.
